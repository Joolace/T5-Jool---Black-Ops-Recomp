// What's inside

Not an emulator.
A native port.

The game code runs directly on your CPU as a 64-bit program, with Direct3D 9 translated to Vulkan. No Windows layer, no x86 emulation on ARM.

Native 64-bit

Built for x86_64 Linux and arm64 Android. Full speed on handheld chips like the Snapdragon 8 Elite.

Vulkan renderer

Direct3D 9 through DXVK, tuned for mobile GPUs, with a persistent shader cache so stutter disappears after the first run.

Upscalers

Render at a lower resolution and upscale with Snapdragon GSR or FSR 1, with adjustable sharpness.

Online and LAN co-op

Join dedicated servers from the server browser, or host on your Wi-Fi. Join mid-round, see everyone's ping. PC and Android play together.

Controller ready

Plug-and-play gamepads and handheld controls, with button remapping and stick configuration in the launcher.

Touch controls

An on-screen layout you can drag, resize and save, both in game and from the launcher.

Vibration & gyro

Rumble on firing, hits and explosions. Gyro aiming from the controller or the device, always or only while aiming.

Auto updates

The Android launcher keeps T5Jool and your Turnip driver up to date by itself.

New menus

A clean main menu, pause menu and loading screens with map previews, your own background and music.

Every map

All Black Ops Zombies maps you own, from Nacht der Untoten to Moon, plus Dead Ops Arcade.

// Getting started

Install in five steps

T5Jool does not include any game files. You need your own legal copy of Call of Duty: Black Ops for PC.

Get the game files

Copy the folder of your PC installation of Black Ops (with zone and main) to your device.

Install T5Jool

Download the latest APK from the Releases page: arm64-v8.2 for Snapdragon 845 and newer (recommended), arm64 for older devices.

Install a Turnip driver

The stock Qualcomm driver does not work yet. The first time you press Play the launcher offers to download a Turnip driver from Mr Purple or StevenMXZ and installs it for you.

Point the launcher to the game

Open Settings in the launcher and choose the game folder.

Play

Tap Zombies or Dead Ops Arcade. The first launch builds the shader cache, so the first minutes can stutter a little.

// Questions

FAQ

Is it stable?

Not yet. T5Jool is alpha software in active development: you may run into bugs, crashes and missing features. Every report helps, use Settings > Report a problem in the launcher.

Does T5Jool include the game?

No. It contains no Activision assets. It only runs the files of a copy of Black Ops that you own.

Is this multiplayer or campaign?

Zombies and Dead Ops Arcade only. Co-op works over your local network.

Which devices are supported?

Android arm64 devices with an Adreno GPU work best today. It is developed on an AYN Odin 3 Pro (Snapdragon 8 Elite). Linux x86_64 with a Vulkan GPU is supported too.

The game closes right after starting

On Adreno devices you need a Turnip driver: the stock Qualcomm Vulkan driver is not supported yet. Install one from Settings > Download a driver.

Why does it stutter the first time?

Shaders are compiled the first time they are needed and then saved. After a match or two the game runs smoothly.

Where is the source code?

It will be released later. Follow the Discord for news.

How do I report a bug?

Use the Logs button in the launcher to save the logs and share them on Discord or in a GitHub issue.
